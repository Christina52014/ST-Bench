# Analysis and reproduction guide

The repository separates two levels of reproducibility:

- **Released-table analysis:** summary tables and the main result figures can be rebuilt directly from `tables/`.
- **Evaluation from model outputs:** the task evaluators accept embeddings, predictions, coordinates, and labels supplied by the user. Raw datasets, model weights, and model-specific training/inference code are not bundled.

## Environment

Use Python 3.10 or newer and install the shared analysis dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the commands below from the repository root. Generated figures are written to `build/figures/`; the `figures/` directory contains only the 12 PDFs cited in the paper's main text.

## Rebuild summary tables

```bash
python scripts/clustering/summarize.py
python scripts/annotation/summarize.py
python scripts/gene_expression/summarize.py
```

These commands read the released full result tables and rewrite their derived summary CSVs.

## Rebuild the main result figures

```bash
python scripts/figures/plot_fig1b_model_characteristics.py
python scripts/figures/plot_fig2_funkyheat_split.py
python scripts/figures/plot_fig3b_annotation_examples.py
python scripts/figures/plot_fig4_gene_expression.py
python scripts/figures/plot_fig5_deconv_funkyheat_filled.py
```

These scripts regenerate the six panels listed above using only files in this repository. The annotation-panel script also recomputes accuracy and macro-F1 from per-cell predictions. The other main-text panels are provided as PDFs in `figures/` but are not regenerated by these scripts.

## Evaluate new model outputs

All evaluators expect rows to be aligned across embeddings, coordinates, and labels. CSV label files must contain one label column; the first column is used. NPY labels are one-dimensional arrays.

### Spatial clustering

Input is an `(n_spots, n_features)` embedding, an `(n_spots, 2)` coordinate matrix, and one label per spot. The evaluator standardizes features, builds a 20-nearest-neighbor graph, searches Leiden resolutions `[0.1, 0.3, 0.5, 0.7, 1.0, 1.5, 2.0]` by ARI, and applies two rounds of majority-vote smoothing over self plus six spatial neighbors.

```bash
python scripts/clustering/evaluate.py \
  --embeddings path/to/embeddings.npy \
  --coordinates path/to/coordinates.npy \
  --labels path/to/labels.csv \
  --model Novae --dataset DLPFC --sample 151507 --embedding frozen \
  --output results/clustering.csv
```

### Cell-type annotation

Input is a reference embedding with cell-type labels and a target embedding in the same feature space. The evaluator uses Euclidean, distance-weighted kNN (`k=15` by default). Target ground truth is optional.

```bash
python scripts/annotation/evaluate_knn.py \
  --reference-embeddings path/to/reference.npy \
  --reference-labels path/to/reference_labels.csv \
  --target-embeddings path/to/target.npy \
  --target-labels path/to/target_labels.csv \
  --output results/predictions.csv --metrics results/annotation.json
```

### Gene expression prediction

Input is a predicted and a measured `(n_spots, n_genes)` NPY matrix with identical gene order. The evaluator reports flattened global Pearson r and column-wise per-gene Pearson r.

```bash
python scripts/gene_expression/evaluate.py \
  --predicted path/to/predicted.npy --measured path/to/measured.npy \
  --output results/expression.json --per-gene-output results/per_gene.csv
```

### Deconvolution

The cosine-softmax evaluator computes a centroid for each reference cell type, applies cosine similarity with temperature 5, and converts similarities to spot-level proportions. With target labels it reports PCC, RMSE, JSD, accuracy, and macro-F1.

```bash
python scripts/deconvolution/evaluate_cosine_softmax.py \
  --reference-embeddings path/to/reference.npy \
  --reference-labels path/to/reference_labels.csv \
  --target-embeddings path/to/target.npy \
  --target-labels path/to/target_labels.csv \
  --probabilities results/proportions.csv --output results/deconvolution.json
```

For the corrected DLPFC protocol, use 33 fine-type probability columns and map them to the five evaluation layers:

```bash
python scripts/deconvolution/evaluate_dlpfc_5layer.py \
  --probabilities results/proportions.csv \
  --labels path/to/dlpfc_layer_labels.csv \
  --output results/dlpfc_5layer.json
```

## External requirements

The evaluators do not train foundation models or extract their embeddings. Producing those outputs requires the original public datasets, each model's source code and checkpoints, and in some cases a GPU. Use the preprocessing and checkpoint settings reported in the paper. Model-specific environments should remain separate because their dependency requirements can conflict.
